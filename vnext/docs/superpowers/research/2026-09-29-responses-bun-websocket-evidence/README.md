# Bun Responses WebSocket acceptance

F3 installs native client WebSocket ingress through the production Bun callback factory on the four exact Responses paths. It reuses the accepted F1 canonical execution and F2 bounded session; native upstream requests remain HTTP/SSE. Authentication completes before upgrade, private continuation is socket-scoped, and every turn rechecks current authority. Workers and shared generated capability remain unchanged pending F4.

Independent spec/quality review approved the six frozen product/test paths with no Critical or Important findings. Final solo `bun run ci:local` exited 0: **4,932 pass / 1 existing skip / 0 fail / 85,078 assertions**; package types, purity, lint, UI build and Workers dry-run passed. Lint retained 35 existing warnings and the multiple-tsconfig advisory. The three retained evidence scripts were added after CI and linted separately with no errors or warnings beyond that advisory. All six product hashes matched after acceptance.

Six fresh frozen runtime processes passed: the F1 HTTP/SQLite/file and workerd/D1 regressions, both F2 session/pressure probes, the new 11-group actual Bun native protocol probe, and the actual paused-reader probe. These retain durable terminal ordering, opt-in retention, provider usage semantics, auth refresh, failure recovery, real upstream cancellation, malformed/overlapping input, cross-socket isolation, binary/max-frame handling, and unchanged HTTP POST. See `runtime-results.json` for exact cases and result boundaries.

The paused TCP reader runs under **Bun's Node-compatible net API**; the SSE producer is an independent **Node child process**. These are actual native sockets, not synthetic send results. The final frozen timeout run observed a 221,435-byte native buffer peak, already-enqueued `send() === -1` frames without retransmission, drain followed by new frames, and close about 5,006 ms after the final send. The upstream was aborted. Abrupt paused-reader disconnect aborted upstream in 5 ms. These figures are observations from one fixture, not throughput guarantees or peer acknowledgements.

The pinned Codex `8ff74cc9` ModelClient passed both actual-gateway filters against a newly started frozen process: zero-inference prewarm followed by same-socket empty-delta continuation with full original state; and failed terminal followed by a fresh-socket full request without HTTP fallback. The independent Node observer counts real upstream calls and the wrapper observes production callbacks without injecting protocol frames. `client-results.json` records the filters and the pinned test harness's inherited unused-import warning. No live provider or production deployment was used.

## Reproduction and limits

Run either `task-C12-F3-native-runtime.mjs` or `task-C12-F3-pressure-runtime.mjs` with Bun and `VNEXT_PROBE_ROOT` set to the checkout root. Their helper is retained in the sibling Responses session evidence directory. The committed copies differ from the accepted scratch versions only by that relative helper import and a Bun lint-global declaration. `task-C12-native-client-fixture.mjs` takes `C12_GATEWAY_SOURCE_ROOT`; its emitted runtime JSON supplies loopback bases for the retained pinned-client runner described in the WebSocket client contract research. All credentials/data are synthetic and all databases are temporary.

Native max input and output-buffer threshold are 1 MiB; F2 still owns 5-second drain, 25-second cleanup, 16-MiB turn output and one 8-MiB latest-only continuation slot with logical 5-minute TTL. `idleTimeout:0` is explicit and accepted by Bun 1.3.0; this pass did not time a generation quiet for more than 120 seconds. Native enqueue is not a delivery ACK. No reconnect replay, multiplexing, native upstream WS or broad client compatibility is claimed.

Writer tests observed client CLOSED and session cleanupComplete:true before a Bun 1.3 server-stop Promise remained pending in two intermediate runs. Final teardown invokes stop without awaiting that Promise. This distinguishes observed application cleanup from native stop-Promise settlement; it does not prove the underlying runtime bug's cause. Retained native probes independently assert provider socket abort. Review's broader normal-suite regression suggestion and inherited lint advisory remain recorded for final review.

No new migration or environment variable. No push or deployment.
