## Modules and immutable identities

- `build.ts`: identical Bun.build options `target: node`, `external: [cloudflare:sockets]`, `naming: worker.mjs`, `sourcemap: external`. No source copying. Workspace exports, including wildcard exports, always resolve to their own variant source. No general undeclared-import fallback exists. The same rule runs on A and B.
- `supervisor.ts`: each detached Bun child owns a process group. Construction/ready/DB/seed/inspector/request/settlement/disposal have separate finite bounds; the parent has a 240-second canary / 480-second formal-unit bound, followed by TERM grace and KILL grace (1.5 seconds each). SIGINT/SIGTERM aborts the current owned child and never starts another. Exit zero alone cannot qualify. A surviving grandchild in the owned group is cleaned even after parent exit. - `journal.ts`, `unit.ts`, `aggregate.ts`, `matrix.ts`: initial false dispositions; globally unique offer IDs journaled/fsynced before fetch; terminal rows and phase/block/stage checkpoints journaled/fsynced outside timed intervals before the next offer. Only matching offered/terminal ID sets with exact cardinality, EOF, both ordinary oracles, dispatch, background settlement, physical readback, cleanup and input identity can collect successfully. Every matrix cell joins one terminal wire result to one physical readback fidelity result.
- `runtime.ts`, `entry.mjs.template`, `upstream-fixture.ts`, `oracle.ts`, `readback.ts`, `inspector.ts`, `cpu.ts`: equivalent observation and deterministic requests across both variants. Ordinary latency isolates have no inspector. The existing diagnostic/canary runtime uses raw workerd inspector without Miniflare's optional proxy. Discovery converts Miniflare's ws URL to HTTP and requires exactly one `id=core:user:<workerName>` with socket path `/core:user:<workerName>` and the exact returned local ws host/port. Wrong IDs/paths, duplicates, proxy-shaped targets and host escape are rejected; titles never trigger first-target fallback. Errors retain observed IDs/titles/sockets; successful attachment identity is journaled and retained in canary/diagnostic artifacts.

## Experiment and completion contract

Five fresh children run sequentially: latency-pair 208, A-matrix 150, B-matrix 150, B-diagnostic 104, A-diagnostic 104. Total 716 = 144 warmup + 160 latency + 252 matrix + 160 diagnostic. Each mode/isolate has twelve warmups. The paired latency child keeps both isolates alive for four AB/BA/AB/BA blocks, ten offers per variant/mode/block. Each matrix has every 3×3×7×2 cell exactly once. Diagnostics preserve each mode's profile immediately after Profiler.stop, before the settled heap query; no GC/snapshot command is issued.

Completion checks actual ID sets and exact per-unit/mode/block/cell shapes, not only counts or exit status. Aggregation re-reads original durable journals and receipts, checks physical supervision, all raw wire request/response hashes and independently reparsed events, durable dispatch/storage records, global ID uniqueness and exactly five successful receipts. `collectionCompleted` describes these physical collection invariants and both strict ordinary outcomes. `noRegression` separately requires no A-passing cell to fail in B for either wire semantics or capture fidelity. Final `completed` requires both. Matrix failures can be complete observations only after physical structure and provenance pass; they remain failures. All A-failing/B-failing pairs retain both details as `unresolved_shared_failure`, without assuming equivalent reasons. The binary gate does not prove universal behavioral non-regression or that every A/B cell meets either desired contract. Unknown, missing, duplicate or inconsistent outcomes disqualify collection.

A uses its own 0001–0014 schema and two request/response owned objects per logical request; B uses its own 0001–0021 schema and three owned objects, including version-1 fetch-body upstream capture. The adapter verifies actual table_info against its declared schema. Formal totals are 716 physical dump rows and 1,790 owned objects, not equal A/B storage work. Zero dump retention enables writing; zero Responses retention requires zero physical snapshot/item rows. D1/KV inventories are recorded per variant and not forced equal.

Physical canonical event fidelity and wire semantic correctness are separate. SSE fidelity compares stored frames with independently parsed wire events, with only the source-supported single protocol-specific renderer `error` frame for failed/truncated metadata paths. JSON frame logs use upstream-producer canonical semantics, including native Responses terminal envelopes. Byte fidelity compares each variant's own exact wire digest. Matrix response-value/semantic mismatches produce failed fidelity outcomes; no frames are deleted, normalized or repaired. Invalid schema/descriptors/ownership, unreadable compressed data, invalid UTF-8 or JSON, untyped frames, invalid timestamps, request-provenance failures and missing/ambiguous raw evidence remain fatal. All 24 matrix warmups and ordinary canary/latency/diagnostic observations require strict wire and fidelity success. No case whitelist exists for baseline defects.

B native sidecars require the full independent fixture body/prefix digest, exact prepared-request prefix/truncation, status/operation metadata and capture budgets. The ordinary Responses/Responses hot request requires full bytes plus `terminal=eof`, `totalBytes=observedBytes`. The only possible complete cancellation representation is SSE upstream Chat with ok/tool/refusal/slow, or any upstream SSE failed: `terminal=cancelled`, `totalBytes=null`, while full observed/captured fixture bytes and complete digest remain mandatory. This follows the source audit's Chat DONE/explicit-failure parser return paths; runtime outcomes remain unverified until Task 2. Host EOF, fixture finish and sidecar EOF/cancelled remain separate evidence. read_error/fetch_error/not_consumed/partial bytes never qualify. B's Responses←Messages JSON refusal dump status 502 versus wire 200 is accepted only for the exact successful policy-refusal oracle cell with complete transport and failed metadata; no such exception applies to A or SSE.

## Durable output schemas

`manifest.json` v1 contains experiment UUID, exact formal count/warmup/expected values, A/B roots/source inventories/migration roots/representation/bundle paths, `execution` with the frozen actual Bun executable realpath/bytes/digest, runtime versions, tools/dependencies/artifacts hashes and physical resolution edges. Its byte digest identifies every child and aggregate.

Each child directory contains immutable stdout/stderr logs, append-only `journal.jsonl`, initially-false/atomically-final `receipt.json`, and parent-owned `supervision.json`. Journal events include `offered`, `terminal`, `stage_begin/end/error`, `phase_begin/end`, `block_begin/end`, `mode_begin/end`, `settlement`, `dump_readback`, `dispatch_readback`, `inspector_target`, `diagnostic`, `cleanup`, `unit_error`. Terminal rows retain ID/cell/phase/block, status, EOF/first-semantic/terminal latency, transport/oracle result, wire/request digests and `wireEvidence` artifact path. The returned runtime row, in-memory row, journal row and raw artifact row share that path. `eofMs` is captured at `reader.done`, before decoder/JSON/oracle/artifact work, and is null if EOF was not observed; caught error duration is recorded separately as `failureElapsedMs`. Each raw wire artifact retains original ingress body, complete decoded UTF-8 wire response, parsed events and DONE evidence; deterministic fixture responses are UTF-8. `wire.ts` reparses raw response text without invoking either oracle, preventing parsed-field changes from detaching observations from raw bytes. Dispatch artifacts retain prepared upstream body, response prefix/body-completion/finish/close evidence. Readback records retain ownership, compressed/decoded sizes and digests, status/canonical evidence and `captureFidelity`.

`captureFidelity` has comparator `response-frame-fidelity-v1`, boolean `passed`, nonempty failure `errors` (empty on pass), original decoded-response `storedSha256`, raw-host-response `wireSha256`, `evidence` (`wireEvidence`, `responseKey`, `responseType`) and `details`. Passing classifications are `exact_wire_bytes`, `exact_wire_frames`, `renderer_appended_error` and `canonical_source_semantics`; failing classifications are `wire_bytes_mismatch`, `frame_value_mismatch` and `canonical_semantics_mismatch`. SSE details retain stored/wire event digests, DONE flags and recursive value differences. Hashes and pointers must match the unique terminal and response object. Wire classifications are the strict oracle's `success`, `expected_refusal`, `semantic_mismatch`, `http_failure`, `explicit_failure`, `false_success`, `truncated_no_terminal` or `transport_or_parse_failure`; classification, pass/error consistency and domain are validated.

A receipt carries exact manifest digest/experiment/unit, expected count, initial/final completed flag, fatal error, all invariant booleans and recomputed ID-set evidence. Supervision carries owned PID, exit/signal, timeout/interruption, TERM/KILL actions and physical cleanup. `aggregate.json` starts false and only qualifies after every receipt/raw journal/input/physical contract and both no-regression gates. `matrix.cells` declares 126 outcomes per variant (zero for canary). Each of `matrix.wire` and `matrix.captureFidelity` contains all 126 `comparisons`, `baselineFailures`, `candidateFailures`, `regressions`, `improvements`, `sharedFailures` and `noRegression`. Each pair retains `cell: [protocol, upstream, scenario, stream]`, full `baseline` and `candidate` outcomes; shared failures add `status: unresolved_shared_failure`. Each outcome retains logical/record IDs, boolean pass, classification, errors and evidence containing raw artifact/request/response hashes plus the full capture result. Legacy top-level failure/regression lists remain terminal wire aliases. The aggregate also retains incomplete errors, local latency p50/p95/block medians, diagnostic profiles/settled heaps and compressed/decoded storage costs.

Interrupted/truncated original journals cannot qualify. Analyze a copy if partial metrics are needed; this runner never repairs originals or silently resumes/retries. An implementation build-check manifest becomes invalid whenever harness bytes change and is not a final measurement freeze.

The accepted matrix observation amendment is explicit in the binding specification. Formal-01 remains incomplete: an offline physical replay of its original A matrix does not supply B, diagnostics or a new experiment. Harness/spec changes require a fresh freeze, canary and formal run before runtime qualification.
